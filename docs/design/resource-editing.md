# 版式资源检索与视觉单页编辑

## 数据与检索

32 份参考 PPT 共 3,708 页；每个源页有稳定 ID、独立 Slidev Markdown、文字槽位
与来源证据。保留来源顺序与文件 SHA-256，宣传/版权/空白页保留记录、默认排除检索。
`packages/resources/manifest.csv` 面向人和轻量工具，`index.json` 面向本地检索。
不把数千页全文塞入系统提示；MCP 分为检索摘要和按需读取源码两步。

检索使用中英文同义词、中文分词和二元词，标题/语义标签优先于样例全文；支持类型、
密度、来源、状态过滤和分页。LLM 在复用结构、组合主题 layout 与逻辑图、自行创作
之间选择；主题 Skill 继续控制字体、色彩和约束。图表、图片和曲线的转换限制随每页
返回，不能将“结构扫描完成”等同于“视觉与可编辑导出全部通过”。

## 前端编辑路径

- 顶部“版式” Tab 浏览、检索、筛选、查看来源和转换限制；可应用到当前选中页。
- 编辑侧栏选择 Slidev 页，右键打开“修改”或“使用版式/逻辑图重做”。
- 预览“重做此页”进入同一编辑对话框；“框选修改”在当前可见幻灯片画布上拖动。
- 预览运行时通过经过 origin/source 校验的消息报告页面及真实画布 bounds；框选覆盖
  真实画布而非 letterbox，归一化到左上原点。反向拖动、越界与极小选区有确定性处理。
- 编辑前保存未保存草稿，确认目标 deck 路径与页码；继承当前对话并创建编辑分支。
  Gateway 在发送时重读目标页与 revision，提供 `<fastppt-target-page>`；LLM 按既有
  page-edit Skill 保留其他页。选区和版式 ID 随指令传递，范围不会自动升级为整页重排。

## 对话体验

使用安全 Markdown 渲染，支持表格、链接、代码与嵌套列表；不执行模型返回的 HTML。
消息可复制。执行活动可展开，错误仍直接显示；保留 Skill 审计与审批能力。
用户滚动阅读时不抢滚动，提供回到最新消息按钮。运行中禁用重复发送，键盘发送尊重
输入法组合状态。模型上下文中的内部指导块从用户消息展示中收起，但继续传给 Agent。

## 边界与验证

素材转换为结构参考，不能承诺所有母版、动画、曲线和图表都是 Office 高保真复刻。
复杂对象的文字与数据保持可查，源文件不变，转换限制与授权说明保留。图表内嵌完整
源数据；值、标签、关系需在实际生成页上重新校验。单页范围目前由 revision、目标
源码和 page-edit Skill 约束；不声称能拦截模型通过任意 shell 路径修改其他文件。

验证覆盖检索与排除页、分页、资源路径隔离、源页覆盖、HTTP/CSP、Markdown 注入、
框选坐标、前端构建、MCP 与浏览器端应用版式/框选/右键流程。独立 DOM 审计报告区分
自动可观测的图片缺失/文本溢出与尚需人工检查的视觉质量。
