# 可复用 HTML 图形与原生 PPTX

资源页保留独立文字、图片和对象锚点。矩形优先使用普通 HTML 背景与边框；多边形、
曲线采样轮廓及有孔洞的复合图形使用 HTML/CSS，并附带受约束的几何元数据。
复杂蒙版、超出几何预算或暂不能保持外观的独立画层保留局部 SVG，明确记录原因。

`data-fastppt-geometry` 是经过 HTML 转义的 JSON：

```json
{"version":1,"paths":[{"points":[[0,0],[1,0],[0.5,1]],"closed":true}],"fillRule":"nonzero","fill":"#2563eb","stroke":"none","strokeWidthRatio":0}
```

坐标相对该对象的 HTML 边界归一化；描边宽度相对边界宽度。生成器可提供
`fillOpacity`、`strokeOpacity`。HTML 对象内部依次绘制填充和描边，捕获时读取当前 CSS
颜色与透明度；调整 HTML 的大小、颜色和透明度后，原生导出随之变化。改变轮廓时应
同步修改 CSS 轮廓和几何数据，不能把不一致的两套形状作为交付结果。

Slidewave 验证元数据尺寸、有限数值、点数和颜色预算，将一个几何对象捕获为一个
`freeform`，跳过其内部 CSS 绘制片段。导出产生 DrawingML `a:custGeom`，而不是 SVG
图片。同一形状的多个轮廓放在同一个 `a:path` 中，孔洞按包围层级纠正方向，保留
开闭路径、填充与描边。对象的后代继承最近的 `data-fastppt-group`，使几何、文字和
图文组合仍可通过原锚点绑定动画。

目录中的 `compositions/<id>.json` 提供源 PPTX 的真实对象名、层级、槽位、连接关系，
以及对应的 HTML 锚集合。几何候选关联和明确的文字映射分别记录；候选分数并不是
对象身份的证明。复用时先读语义图，再检查对象和相邻依赖，按当前主题重组内容。

验收分开记录：转换是否覆盖全部页面、文字与锚点是否保留、逐页浏览器像素差异、
DOM 内容与溢出检查，以及原生 PPTX 的结构和可编辑性。旧 SVG 重建时的视觉分数
保留为历史记录，不用于认证当前 HTML。自动检查不等于在 Microsoft PowerPoint
中逐页人工验收动画或所有专有效果。
