# Kerning：字号阈值与实际字对位置

2026-10-09。[可重放报告](kerning-libreoffice-7.3.7.2.json)包含 20 页实际原生导出：10 页吻合、9 页已知差异、1 页仅观察，0 页未预期差异。原生 `kern` 阈值、字号和原文均保留；LibreOffice 7.3.7.2 在测量的样例中仍对低于阈值的文字启用 kerning。浏览器像素等价为 `unverified`。

```sh
pnpm --filter @fastppt/e2e exec tsx scripts/kerning-compatibility.ts /tmp/fastppt-kerning-compatibility
```

需要 LibreOffice 7.3.7.2、系统 Python UNO、fontconfig、Liberation Serif、DejaVu Serif，以及可导入 fontTools／PyMuPDF 的 `python3`。本轮使用 PyMuPDF 1.28.2；产物在 `.fastppt/validation/kerning/`。报告绑定实际 PPTX、PDF、原始字形 JSON、初始应用配置、字体文件和复现脚本的 SHA-256。生成后只读检查，不修改 XML，不用诊断副本替代真实输出；共享 LibreOffice 探针保持不变。

独立预期来自实际安装字体的 `hmtx` advance、`kern` 字对表与 units-per-em，不调用浏览器布局函数。文本选用 `AVATAR To WA`，避免额外连字特征影响比较；按声明字号达到阈值决定是否加入字对调整，并独立加上字符字距。报告保存字体度量和预期坐标，离线回放重新计算预期并比较原始 PDF 字符的起点、字号、字体与行归属。位置容差为 0.5pt（覆盖应用的度量量化和逐字符累计偏差），字号容差 0.05pt，行基线容差 0.25pt；关闭 kerning 的字对差异明显大于这些容差。

| 样例 | 页数 | 观察 |
| --- | ---: | --- |
| 20pt 字号，阈值 0／19／20pt | 3 | 字对调整与独立字体度量吻合；零表示始终启用 |
| 20pt 字号，阈值 20.01／21／4000pt | 3 | 源模型应关闭，应用仍启用；保留为已知差异 |
| 20pt 阈值，字号 19／19.99／20.01／21／40pt | 5 | 低于阈值的两页仍启用；其他三页吻合，原生精确字号独立核对 |
| 阈值 0／4000pt，字距 ±1pt | 4 | 字距保留；4000pt 阈值的两页仍额外应用字对调整 |
| DejaVu Serif，阈值 0／4000pt | 2 | 第二种已安装字体重复观察到阈值差异 |
| 空段、软换行 | 2 | 空段保留默认而不虚构字形；软换行保留原字符和 60pt 行距，但阈值仍未关闭调整 |
| 未安装的指定字体 | 1 | 仅记录实际替换字体和位置，不把替代字体度量声明为源预期 |

打开文件前逐字符检查 `kern`／`sz`、指定字体、段落默认、软换行和段尾；UNO 再次读取原文。PDF 提取关闭分析器的合成空格。`source.expected` 使用字号阈值，`source.known` 使用已观察到的始终启用行为；两者分别保存，不能用已知行为覆盖源规则。缺失字体的样例没有源度量预期，状态为 `observed-only`，不计入匹配或修复结果。

`kerningThreshold` 使用点值，DrawingML `kern` 为百分之一点，范围 0–4000pt；缺省继承，零为所有字号启用。字号与阈值同随画布横向比例缩放，XML 按 0.01pt 取整。该字段已贯通九级字符默认、统一固定文字、IR／MCP、模板声明所有权和真实回读。页面作者可以用 `data-fastppt-kerning-threshold="20"` 覆盖；不要把 CSS 的开关状态反推成源阈值。

生成主题嵌入同源、无外部依赖的阈值运行时，按实际字号与源画布计算 `font-kerning:normal/none`；挂载、字号修改、画布缩放和字体加载会重新计算，再进行项目符号／制表测量。固定文字也有独立布局钩子，MCP 生成的布局和独立 Slidev 均不依赖 Gateway 注入。捕获保存阈值像素值并在原生导出时换算点值；检查 CSS、元数据以及额外字体特征是否与契约一致。源文字显式关闭 kerning 却没有阈值契约、冲突的 kern 特征、可变字体轴和未建模拉伸会阻断；未声明的源事实不由开关猜测。

关闭 kerning 时，文字宽度使用设置了相同模式的 Canvas 测量。修复了 Canvas 字体简写中的 `100%` 拉伸值导致整条字体设置无效的问题，防止回退默认字体后低估固定文字宽度。浏览器回归覆盖阈值等号与两侧、零值、局部字号、混排、链接、空段、软换行、Tab、折行、编辑、缩放及错误元数据。原生回读验证独立 run／BR／段尾和布局所有权，原始可编辑字符不因 kerning 改变。

参考 `pptx-renderer@2e8cd2222a889451bc872df50941f927cc79c7a2` 的百分之一点解码和字号阈值到 CSS 开关映射。FastPPT 同时缩放字号与阈值，保留零与缺省，复核实际 CSS，并使用独立应用证据；不会把浏览器开关成功视作目标应用完成验收。

明确声明阈值的正文、模板占位符及固定文字附加 `text-kerning-compatibility`，对象报告保留差异原因。任意字对、所有字体特征、复杂脚本及跨应用精确排版没有由这 20 页验证；PowerPoint／WPS／Keynote 与实际 PPTX 渲染规则门禁仍待后续验收。
