# 项目符号首行几何：独立应用证据

2026-10-09。可重放报告：[bullets-libreoffice-7.3.7.2.json](bullets-libreoffice-7.3.7.2.json)。本轮实际原生导出 46 页：29 页吻合、15 页已知差异、2 页仅观察、0 页未预期差异。这里只验证水平位置、字宽、行归属和所选字体；垂直基线仍标为 `unverified`，没有提升跨应用支持等级。

运行方式（需要系统 LibreOffice 7.3.7.2、Python UNO、Poppler 及 Liberation 字体）：

```sh
pnpm --filter @fastppt/e2e exec tsx scripts/bullet-compatibility.ts /tmp/fastppt-bullet-compatibility
```

参数为输出目录；可省略以使用上述默认目录。本轮保存的产物位于仓库根目录 `.fastppt/validation/bullets/`。

探针使用真实 `writeEditablePptx`，打开前检查正文仍在唯一内容 shape、一个原段落中，保持源缩进、对齐、buChar/buAutoNum、字体和字号属性。每次启动独立只读 LibreOffice 配置，验证实际 en-US 系统区域设置，导出 PDF 前不改动文档。报告绑定 PPTX/PDF、初始配置、字体 XML 和两个复现脚本的 SHA-256，并核对导入文本、页数和页序。此次没有移除缩进的诊断副本。

固定样例使用 186pt 框宽、40pt 左边距、20pt Liberation Mono 正文和 30pt 行距。正文每字符独立预设 12pt advance，Serif 字体星号预设 10pt；预期行列表在生成前固定，不调用浏览器布局辅助函数。Poppler 会将紧邻的标记和正文合并成一个 PDF word，比较时按标记前缀与等宽正文拆开，保留原始 word 供复核。水平容差为 0.25pt。`pdftohtml` 字号为整数近似，字号检查容差为 1pt；实际字宽仍按 0.25pt 检查。字体资源名另以 `pdffonts` 复核，防止其 family 字段省略 Bold 后缀。

| 样例 | 页数 | 结果与限制 |
| --- | ---: | --- |
| 显式 Mono 字体 × 四种对齐 × -20/0/20pt 缩进 | 12 | 水平几何吻合 |
| 随正文字体 × 同样组合 | 12 | 已知差异：实际星号使用 OpenSymbol，宽约 7.77pt，源 Mono 预期为 12pt |
| 50%/200% 字号 × 左/中/右对齐 | 6 | 水平几何和字体吻合；不代表基线等价 |
| 显式 Liberation Serif × 左/中/右对齐 | 3 | 标记宽约 10pt，水平几何吻合 |
| 固定 36pt 字号、固定 36pt + 长词 | 2 | 已知差异：源 buSzPts=3600 保留，应用使用约 20pt，改变首行容量 |
| 长编号 1234. × 左/中/右对齐 | 3 | 原生 buAutoNum 保留，标记超出悬挂区后的首行占用吻合 |

| 粗体正文 | 1 | 已知差异：应用保留常规标记字体，正文使用 Mono-Bold |
| 超宽正缩进、标记后 Tab | 2 | 仅记录；超宽前缀在浏览器捕获时阻断，Tab 另由文字流探针验证 |

浏览器实现将标记与正文分开，使用 `max(0, sourceIndent + markerAdvance)` 作为首行 CSS 缩进。无内容的普通 inline 探针定位首行及标记基线，避免引入断词机会；续行保持段落边距。原生捕获仍取 sourceIndent，动态居中／右对齐后的标记 X 不会写回源缩进。没有向正文加入符号、空格、占位字符或自动换行。

捕获验证生成节点的结构、位置、字体、大小、颜色、可见性、基线与首行占用。非零字号的基线探针、额外内容、改变的标记样式、过期位置和不匹配的点值字号都会阻断。前缀占满段落宽度、RTL、非普通断词规则，以及居中／右对齐段落中的 Tab 仍未放开。点值／百分比、字体跟随、长编号、长词、空段、软换行、左对齐 Tab、缩放、编辑和独立主题运行均有浏览器回归。

导出正文与模板定义均附加 `text-bullet-compatibility`，对象报告保留这些原因；原生属性完整不等于目标应用视觉相同。该报告目前是研发回归证据，尚未接入实际 PPTX 渲染规则门禁，也未完成 PowerPoint/WPS/Keynote 的编辑、播放、保存与重开矩阵。

参考采用的是 `pptx-renderer@2e8cd2222a889451bc872df50941f927cc79c7a2`（Apache-2.0）的段落标记职责分离。其 TextRenderer 在符号后增加空格，并对部分居中悬挂使用 inline-block；FastPPT 的字宽模型和普通 inline 基线方案由独立探针与浏览器断词实验确定，未复制这些布局假设。

旧版本已生成主题的纯文本绝对定位标记继续支持原有负缩进／左或两端对齐子集，并复核源缩进和点值字号；新几何必须携带基线探针。
