## 修复内容与证据

- 生成目录、CSV、说明和前端不再显示用户要求移除的声明；扫描器不会重新写入。
- 从原稿 PDF 保留独立矢量绘制对象、背景、遮罩和本地图片，文字继续是 HTML。
- 修复字号/字距、基线、倾斜与剪切变换、字符位置、跨图层绘制顺序、透明度及透明组叠加。
- 纠正 HTML 自闭合 div/template 导致的空白预览，加入“实际渲染文字数量”校验。
- 原稿故意裁切的大号数字单独记为 intentional bleed；检查可见部分，不将它们挪回画布。
- 29 页使用从 PDF 内嵌字形与 ToUnicode 映射重建的 WOFF2，文字保持可编辑。
  67 个唯一字体、13,033 个 Unicode 映射通过字体检查；TrueType 按原编码表取 GID，避免标点串字。
- 511 页保留图表原始数据的 `data-fastppt-chart` 元数据。
- 前端“对照原稿”支持并排查看与方向键翻页；预览保持无脚本 sandbox。
  字体的 opaque-origin CORS 仅允许资源库哈希 WOFF2 的 GET/HEAD，不放开工作区接口。

主要文件位于 `packages/resources/visual-comparison/`：

- `original-render-report.json`：32 份原稿的页数、来源摘要及渲染器记录。
- `browser-comparison.json`、`comparison.json`：3,708 页的边界、图片、图像指标及文件摘要。
- `contacts/all-*.jpg`、`review.html`：全库原稿/复刻联系表与逐页对照查看器。
- `model-visual-review.json`：模型视觉复核范围和末轮差异说明。
- `slidev-runtime-check.json`：真实 Academy Slidev 运行时的 5 页检查，包含普通逻辑图、
  透明图层、仿射文字、动画遮挡和内嵌字体页；无浏览器异常。
- `source-fonts.json`：字体来源 xref、覆盖字符、资产和实际字形边界。

发布脚本逐项验证原 PPTX、Markdown、两张对照图片及被引用资产的摘要；索引、CSV、审计报告

## 验证边界

原稿比较基准是 LibreOffice 静态导出的 PDF，不等于 Microsoft PowerPoint 对所有动画、字体和
专有效果的表现。图表标签和表格文字可编辑，但本次资源复刻不承诺导出为原生 PowerPoint
chart/table；独立 SVG 对象也不等于每条路径都能原生编辑。重用资源后仍需按所选主题做页面
检查和导出验收。二进制素材遵循现有 Git 忽略策略，新环境需安装或按 README 重建本地资源包。
