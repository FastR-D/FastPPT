# 创意动效分库与运行时验证

验证日期：2026-10-27。

动画库以创意效果为用途，支持文字、图片、遮罩、路径、旋转、弹性及多对象编排。
`packages/animations/` 保存独立的目录、CSV、对象动画 JSON、Slidev 演示单页和 LLM 使用说明。
前端支持搜索、播放、拖动进度、提取单个对象效果、整组绑定和保存。
应用只修改目标对象的动画数据；演示页不是需要替换现有内容的版式。

专用动画来源的 211 页已从 `resources` 移至 `animations/reference`，其中 206 页有动画。
静态版式库现有 3,497 页、31 份来源，原稿 PPTX 保持不变。原有逐页视觉证据随来源迁移，
版式审计与联系表重新绑定当前索引。动画索引包含 1,230 个参考、13,326 段效果实例；
含普通版式中可复用的对象动效，这些数字不代表独立动画算法数量。

| 全库数据、原生 XML 校验、公式 61 个采样点 | 1,230 个参考、13,326 段效果，错误 0 |

| 浏览器端到端流程 | 3 项通过 |
| Slidewave/Web 生产构建 | 通过 |

端到端流程覆盖创意库检索、实际 Slidev 元数据播放、原生与基础预览切换、
捕获前恢复基础几何，以及 Slidewave 可编辑 PPTX 导出。导出验证包含原生组合形状、
原始动画公式、逐项迭代节点、目标/时间 ID 以及生成 XML 的完整性。

动画 XML 经过白名单校验，再映射为目标对象；浏览器公式使用有界算术解析，
不执行任意 JavaScript。原稿无限循环或超过 16 轮的循环适配为两轮，
原始 XML 保留为 `nativeOriginalXml`。用户调整持续时间后，导出同步缩放时间。

浏览器按整体预览逐字/段落迭代，随机公式固定种子以支持拖动，部分遮罩采用近似效果。
原生 PPTX 保留受支持的行为树及迭代；原图表/文本子范围适配为目标对象整体。
这些检查不等于在 Microsoft PowerPoint 中逐页进行了动画视觉一致性验收。

证据：`packages/animations/audit.json`、`browser-compatibility.json`、
`validation/browser-audit.json`；浏览器报告与数据审计均记录当前索引 SHA-256。
