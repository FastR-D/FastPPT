# 动效预设与预览偏好

动画面板支持静态、克制商务、逐步教学和产品揭示。选择“仅本页”或“全部页面”，点击“应用预设”，预览后点击“保存动画”持久化。

预设默认保留已有用户/代理配置，包括 Markdown 中声明的点击动画和页面过渡。动画文件中的显式配置优先于 Markdown；空的静态覆盖也会保留。面板会显示保留页数。需要替换时勾选“替换已有动画修改”。手动添加、修改或删除效果后，该页标记为用户配置，后续预设更新不会自动覆盖。

预设只自动选择有明确语义的对象。HTML 标题自动识别为标题，正文可声明：

```html
<div id="key-point" data-fastppt-role="content">核心观点</div>
<div id="always-visible" data-fastppt-role="content" data-fastppt-static>保持静态</div>
```

未声明角色的容器、装饰图片、logo、页码、背景与主题继承框架不自动添加动画。需要动画的固定对象可提供稳定 anchor，并在目标列表中显式选择。

“预览动态效果”提供跟随系统、减少动态效果和完整动态效果，选择保存在本机。减少动态效果将飞入/缩放替换为透明度过渡，停用脉冲/摇摆/路径运动；它不修改保存的动画或 PPTX 交付配置。

主题 manifest 可通过 `motionPreset` 声明 `static`、`business`、`teaching` 或 `reveal`，主题设计输入也支持同名字段。面板读取该推荐值作为初始选择，只有用户点击应用才更改动画；未声明时默认静态。完整效果注册表仍待接通。浏览器回归与 PPTX 结构测试不代表所有 Office 客户端已验收。
