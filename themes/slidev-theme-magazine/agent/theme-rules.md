# Magazine theme rules

- 每页一个 big idea：标题是章节命题/信息，页内每个模块都服务它。
- 叙事页用全幅去饱和纪实摄影 + mist-white 横带（≤4/页）；数据页纯白 + 顶部/底部发丝线。
- 铜棕只作主系列/单一结论，覆盖 ≤15%；暖金只作小高亮（≤3/页，财务图上方）。
- serif 标题与大数字，sans 正文/数据；大标题倾向 ALL CAPS 章节角色。
- 图表减到故事线：少系列、直接标注；不用彩虹色。
- 禁卡片默认分组、禁蓝紫渐变/玻璃拟态/发光边框、禁摄影进入数据区。
- 摄影用真实纪实图（建筑/材质/工艺/人/现场），不用插画或生成场景替代。
- 引用、单位、测量背景必须落在证据所在页面；不虚构来源。
