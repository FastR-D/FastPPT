# Strategy theme rules

- 每页标题必须是完整断言句（结论），附一行范围/读法副标题。
- Deep forest green 承载结构，bright green 只标关键证据，magenta 仅用于数据级风险。
- 正文页高密度：2–4 个证据模块、1 主图 + 侧栏解读；数字带单位与时间范围。
- 配对内容用 two-cols，全宽主张用 statement，章节页用 section（左竖照片 + 薄荷覆盖）。
- 用 ChapterBar 章节导航、SoWhatBar 底部一句结论；每页各至多一次。
- 禁圆角卡片默认分组、禁三等分默认构图、禁蓝紫渐变/霓虹/彩虹、禁无数据含义的彩色块。
- 不把摄影铺满正文页，也不在照片上叠正文。
- 用细绿线分隔证据，不用堆叠色块构建结构。
- 引用、图片署名、单位、机构声明必须落在出现证据的页面上；不虚构来源。
