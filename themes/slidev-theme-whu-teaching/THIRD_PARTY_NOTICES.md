- These images are retained for the requested reference-derived theme. Ownership and any third-party rights remain with their respective holders; the code package's MIT license does not relicense the source artwork. No public reuse license was inferred.
- Microsoft YaHei and Arial are referenced as local system fonts only; no proprietary font files are bundled. Noto Sans SC and Fira Code are provided by the workspace `@fastppt/fonts` package under its OFL terms.
- Palette and geometry were read from the reference PPTX; the teaching layouts are reusable Vue/HTML reconstructions rather than rasterized source slides.
