# Source layout contract

Only materialized, reachable source layouts are listed below. Geometry is shared with native-layouts.json; font/style fidelity and target-application editing still require review. Partial candidates remain in layout-candidates.json.



For each text placeholder, use a named Slidev slot and a unique content anchor. Bind that anchor explicitly with geometry: layout; preserve page text formatting unless the native placeholder provides textStyle defaults. A binding target must export as one native shape. Script fonts in textStyle.fontFamilies (latin/ea/cs) are projected into ordinary slot text; generated font spans remain one captured text object per authored text run. Paragraph defaults and sparse textStyle.levels overrides are independent for levels 1–9; nested lists select their depth, and data-fastppt-level on p/headings/li selects an explicit level. Empty paragraphs retain a line. textStyle.language and alternativeLanguage preserve independent lang/altLang declarations, including an empty string for unknown language; omitted fields inherit. Source slot text uses lang and data-fastppt-alt-lang, with authored ancestor or inline attributes overriding template defaults. A layout binding removes only language groups explicitly declared by the corresponding level. Uniform fixed text supports the same fields; mixed run languages remain partial. Language identifiers do not control decimal-tab separators or establish target-application typography support. textStyle.underline and strike independently use true for a single line, false for explicit cancellation, and omission for inheritance. Source runs use solid current-color continuous lines; decorations are applied to leaf text spans so cancellation works. Use data-fastppt-underline and data-fastppt-strike with true/false on authored paragraphs or inline elements to override template defaults. Paragraph and soft-break metadata preserve defaults without drawing ancestor decoration; ordinary HTML u/s keep their CSS propagation. Empty paragraphs and soft breaks retain independent native flags. Uniform fixed text supports the same fields. textStyle: layout removes only decoration properties owned by the corresponding level; page retains local cancellation. Capture rejects malformed declarations and mismatched line styles, colors or geometry. Double/wavy lines and custom underline fill/line properties remain located partial. Native decoration semantics have a 12-page LibreOffice probe; browser pixel equivalence and other target applications remain unverified. textStyle.letterSpacing is additional character advance in points: omission inherits, zero clears, and negative values condense text. It scales with the source canvas width, including independent levels and uniform fixed text. Finite values between -4000 and 4000 points are accepted, and native spc is rounded to hundredths of a point. Use ordinary inline CSS for page overrides; letter-spacing:0 cancels a template value. Explicit zero is restored after writer serialization, and paragraph, empty-line and soft-break defaults remain independent. textStyle: layout removes only a declared spacing field; page retains captured run values. Nonzero spacing carries text-letter-spacing-compatibility: the 18-page LibreOffice probe has 15 matches and 3 known Latin/CJK boundary differences even with installed fonts. Review mixed-script spacing and wrapping in the target application. textStyle.baselinePercent is a percentage of the declared font size: positive raises text, omission inherits, and zero clears. Ratios do not scale with the canvas; declared font sizes do. Source integer baseline values use thousandths of a percent, with native rounding to that unit. Use data-fastppt-baseline="30" or "0" for authored overrides in source layouts. Generated leaf spans preserve declared sizes and line boxes, and capture validates the measured offset before retaining the native percentage. Paragraph, empty-line and BR defaults are separate; BR also retains its declared font size. Uniform fixed text moves its inner text, preserving the outer object box. Invalid metadata, inconsistent CSS, rotated/nonuniform text and unmodeled sup/sub remain blocked. Native export carries text-baseline-compatibility: LibreOffice 7.3.7.2 shrinks tested nonzero-baseline text to about 58%, truncates fractional percentages, and can alter line placement/wrapping. Source preservation is not browser/application pixel equivalence; verify the actual output. textStyle.kerningThreshold is the minimum font size in points for kerning, from DrawingML kern in hundredths of a point. Omission inherits and zero enables kerning at all sizes; accepted range is 0–4000 points. Threshold and font size scale together with the source canvas width. Use data-fastppt-kerning-threshold="20" for an authored override. Generated layouts embed a standalone runtime that evaluates measured font sizes on mount, font loading, resizing and CSS edits before tab geometry is captured; fixed text is included. Capture retains the threshold and rejects inconsistent CSS, conflicting font feature settings, unmodeled stretch/variation and disabled source kerning without a threshold contract. Runs, BR, empty paragraphs and paragraph ends preserve independent defaults; layout binding clears only its declared kern field. Declared thresholds carry text-kerning-compatibility: a 20-page LibreOffice probe has 10 matches, 9 known cases where kerning stays enabled below the threshold, and one missing-font observation without a source metric claim. Review actual target typography. textStyle.capitalization preserves DrawingML cap as none/all/small; omission inherits and none explicitly cancels. It changes display only: editable text remains the original Unicode string, including sharp s, ligatures and language-dependent characters. Use data-fastppt-capitalization="none" (or all/small) on authored source paragraphs or inline elements. Generated leaves use validated text-transform/font-variant-caps metadata; capture keeps source text and actual DOM widths. Paragraph, BR, empty-line and paragraph-end defaults remain independent, and layout policy removes only its declared cap. Uniform fixed text supports the same fields. Uncontracted transformed source text, conflicting CSS, extra font features or small-cap synthesis overrides block capture; a single source grapheme spanning multiple line boxes requires an explicit text frame. Tabs and automatic lines retain original UTF-16 ranges. Font embedding keeps full relevant face coverage for uppercase expansion and small-cap substitutions; variable fonts still instantiate the declared weight, and size limits can prevent embedding. all/small carry text-capitalization-compatibility: the 36-page LibreOffice report preserves every source string but observes capital sharp s instead of SS, retained Greek accents, truncated ligature expansion and small caps drawn as full capitals. The generic Chrome reference distinguishes synthetic small caps from actual smcp font features; neither it nor display-text matches establishes cross-application pixel equivalence. For one native placeholder containing several paragraphs or inline styles, place the content inside a div with a unique id and data-fastppt-text-box in a source slot with paragraph/levels defaults. This explicit text frame preserves paragraphs, soft breaks, empty paragraphs, character styles and links as one native shape. Do not put separate anchors on its children. Images, effects, clipping, complex positioning, uncontracted bullets, unsupported numbering schemes, unmeasured tab layouts, RTL and unsupported content inside the frame produce a located capture error and block export. Without this marker, multiple authored nodes still export separately and cannot share one placeholder binding. textStyle: page retains inline emphasis; textStyle: layout removes every local override declared by the layout. Source textBody defaults carry insets, vertical alignment, wrapping and no-autofit. Set textBody: layout explicitly to inherit declared body properties; this policy is independent of geometry and textStyle. An explicit text box that is the only direct content of a source slot captures the complete frame and its measured insets. Character and automatic-number paragraphs require this explicit text frame. paragraph.bullet selects none, character, or auto-number (scheme plus optional template startAt); bulletFont, bulletSize and bulletColor independently select explicit values or follow the first visible run. Browser measurement covers left/center/right/justified LTR bullets, including nonnegative indents and markers wider than the hanging gutter. First-line occupancy is max(0, source indent + measured marker advance); continuation lines retain the paragraph margin. Empty inline baseline probes preserve long-word breaking and align the marker with the first line without adding body characters. Capture verifies marker structure, font, size, color, position, baseline and first-line occupancy, then exports the original source indent. A prefix consuming the whole paragraph and unsupported break rules remain blocked. Tabs still require a left-aligned paragraph. Native rendering may use different marker fonts, sizes or emphasis; text-bullet-compatibility reports the measured LibreOffice limitations. Empty paragraphs retain their bullet contract but show no marker. Use data-fastppt-no-bullet on a paragraph or list item for local cancellation, and textStyle: page to retain it. Markers remain separate from body text and export as native paragraph properties; changing a marker inconsistently blocks export. Automatic numbering supports arabic Period/ParenR/ParenBoth/Plain and alphaLc/alphaUc/romanLc/romanUc with Period/ParenR/ParenBoth (1–32767). Counters are independent per text frame and recomputed in DOM order. Nonempty parent list items reset child counters; plain interruptions and empty paragraphs do not consume numbers. Use data-fastppt-start-at on p or li for an explicit local restart; it is separate from the template starting value. A li restart applies to its first projected paragraph. textStyle: layout may override local numbering, so use page to retain restart intent. Restarts or changed starting values within an existing sequence, and empty-paragraph restarts, carry a numbering-compatibility warning: LibreOffice can ignore a restart at 1 or adjacent equal starts. Target-application typography and numbering still require review. Paragraph defaultTabSize and tabStops independently preserve inherited, zero, and explicit empty-list intent; positions are EMU from the paragraph left margin. Source browser measurement supports left, center, right and explicitly declared decimal stops in left-aligned LTR paragraphs inside explicit text frames. Literal tabs or HTML &#9; are retained across runs, consecutive stops, soft breaks, edits and canvas resizing; generated setup/vite-plugins.ts preserves them before Vue compilation. Keep setup in the installed theme. Fields extend through inline runs and end at the next tab or explicit soft break. Center/right alignment measures the entire field; a field too long to align uses a zero-width tab gap without jumping to a different stop. Default stops after the explicit list are left-aligned. Pre-wrap paragraphs with ordinary word breaks measure automatic lines, including long words. Tab spacers are iterated until their line positions stabilize, reselecting stops after a line move. Captured tabLayout records original UTF-16 ranges, authored versus automatic breaks, tab offsets and measured bounds; automatic lines never become extra native breaks. Unsupported whitespace/break rules, unstable or invalid spacers, undeclared decimal conventions and zero default spacing without a following explicit stop block capture. Font metrics at an exact boundary can still change native wrapping; the export warning requires actual target review. Tabs remain native characters with defTabSz/tabLst in one shape. Export reports text-tab-compatibility because LibreOffice 7.3.7.2 can reset stops with explicit indent and ignore custom default spacing or empty-list clearing. Decimal alignment requires textStyle.paragraph.decimalTab (or the corresponding level override): separator, user-declared provenance, a reason, and a measured targetProfile. Null clears an inherited declaration. Supported measurement profiles are libreoffice-7.3.7.2-linux-en-US (period), -de-DE and -fr-FR (comma); they pin diagnostic evidence, not successful native compatibility. Import with --decimal-tabs <source-bound-declaration.json> alongside --analysis to apply an explicit convention; SOURCE_SELECTION.json keeps the extracted unknown state and user declaration separately. Browser measurement aligns the first separator glyph edge or the field end when absent. DrawingML preserves dec but cannot store the separator or enforce a locale; keep this sidecar and review actual output. A run language alone does not determine decimal alignment. Target-application review is still required.
