# Eloc theme rules

- 使用短标题、少量要点和清晰代码层级。由于只有 default 布局，应通过 Markdown、代码块和有限列布局组织内容，避免无意义卡片化。
- Use only layouts declared in the theme manifest.
- Keep one idea per slide and prefer concise fragments to prose walls.
- Preserve the upstream 16/9 canvas, palette, typography, and component language.
- Verify citations, image credits, data units, logos, and external assets.
- Run FastPPT preview and overflow checks, then visually review every changed layout.
- Do not copy styles or components from another theme into a deck.
