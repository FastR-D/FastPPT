# xiaomi theme rules
- 使用小米橙 #FF6900、正文 #11161A、画布 #FFFFFF、冷灰 #F3F5F6；禁止回退到 Office 默认蓝色。
- 全局使用 MiSans；标题通常 46–72px，正文 20–24px，标题最多两行。
- 每页一个主张，以大产品图、强数字或单一信息结构为主，保留大面积非对称留白。
- cover 用于产品主视觉，section 用橙色短线转场，two-col 用于 45/55 对比，metrics 用深色底承载关键数字，ending 收尾。
- 避免密集卡片阵列、胶囊标签云、通用企业蓝、装饰性渐变和无意义图标。
- 引用、单位、来源落在证据所在页面；不虚构来源。
