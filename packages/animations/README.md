# FastPPT creative motion library

Object motion for creative composition, separate from static layout resources.
The dedicated animation source's 211 pages are archived under `reference/`,
including their cleaned static reconstructions and source PDF. Generated
screenshots and thumbnail caches are removed; playable previews render on demand.
206 presented pages contain timing effects (some source slides reuse an XML part).

The active library extracts 1,230 motion references and 13,326 effect instances
from all available local reference PPTX files. A reference can contain several
objects and effects; these counts are not counts of distinct animation algorithms.

- `manifest.csv`: effect name, creative use cases, category, scope, timings and limitations.
- `index.json`: bounded local search catalog; creative-source references rank first.
- `motions/<id>.json`: AnimationDocumentV1, original native behavior XML and browser parameters.
- `pages/<id>.md`: neutral editable demo objects plus inert motion metadata.
- `reference/`: migrated source pages, source PDF and historical measurement metadata; never used as an animated screenshot.
- `migration.json`: source hashes and ownership; the resource scanner skips the moved source.
- `SKILL.md`: LLM retrieval, binding, composition and verification contract.

Run `python3 packages/animations/scripts/import-pptx.py` to regenerate motion
metadata without changing any source PPTX. Static layouts with incidental motion
remain in `resources`; their reusable object effects are indexed here separately.

API: `GET /api/v1/animations`, `/facets`, `/:id`, `/preview/:id`.
MCP: `search_animations`, `read_animation`. The web Animation tab offers search,
playback, scrubbing and explicit source-object → destination-object binding.
Application changes animation metadata only, retaining the page's existing content.

Slidev reads `data-fastppt-motion` metadata through the Slidewave runtime. On entry,
automatic effects play; arrow keys advance click groups before navigating pages.
The same effect data works with the timeline preview. Capture cancels motion and
restores the base object geometry before snapshotting.

Slidewave preserves native behavior XML after validation, replaces shape/time IDs,
normalizes missing IDs, scales timing when the user changes duration, and forms
native groups for captured multi-primitive objects. Unsafe external behavior nodes,
dangling timing dependencies, missing targets and interleaved grouping are rejected.
Native XML timing does not guarantee identical playback across PowerPoint versions.

Browser preview is an adaptation: arithmetic, scale, rotation, opacity and paths
are sampled into Web Animations; randomized formulas use a stable seed for scrubbing.
Letter/paragraph iteration previews as a whole object. Random bars/strips and some
reveal masks are approximated. Sub-chart and paragraph selectors are adapted to a
whole destination object. Unsupported properties are listed per reference. Original
native formulas, iteration and supported behavior trees remain in PPTX export.
Infinite loops and source loops longer than 16 cycles are normalized to two cycles
for creative reuse in both players. Their original XML is retained as
`nativeOriginalXml`; original PPTX files remain unchanged. Root acceleration,
deceleration, repeats and auto-reverse are included in browser timing.

`FASTPPT_ANIMATIONS_ROOT` selects an external pack. The packaged CLI optionally
copies the active pack with `FASTPPT_BUNDLE_REFERENCE_ANIMATIONS=1` (historical
reference renders are omitted). No third-party reference pack is bundled by default.

Each active demo uses semantic native HTML objects with named replacement slots.
`index.json` includes optional `objects` and `objectRoles` fields for retrieval;
source shape type, text and bounds help select a suitable destination object.
`scan-report.json` records HTML/SVG counts, covered/missing targets and base-layout
versus animated overflow risk for every page. Dense sequences retain every source
anchor as a separate CSS particle. No demo screenshot is generated by import.

Validation commands (screenshots are opt-in and are not library assets):

- `pnpm --filter @fastppt/animations test`
- `packages/animations/node_modules/.bin/tsx packages/animations/scripts/audit.mts`
- `node packages/animations/scripts/audit-html.mjs` checks all 1,230 base DOM layouts.
- `node packages/animations/scripts/audit-browser.mjs` checks all 206 dedicated
  demos against the local gateway on port 4317 and seeks their live timelines.
