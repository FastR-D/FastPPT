# Slide content standards

These rules apply to every deck and every theme. The active theme Skill owns
visual language (color, layout, components, density); this file owns what the
words say. A slide has a few dozen words at most, so AI phrasing is far more
visible here than in prose. Write like a confident analyst, not a marketing bot.

## 1. Titles carry the argument

A title is a complete assertion, ideally with a number and an outcome — not a
topic label, not a question, not a slogan.

| Avoid | Prefer |
| --- | --- |
| `# 关于转化率的思考` | `# 转化率提升 30% 的三个杠杆` |
| `# 如何提升用户留存？` | `# 流失集中在次日，7 天留存是关键` |
| `# 洞见未来` | `# 订阅制收入两年从 0 到 40%` |
| `# Margin compression` | `# Margin compression is structural, not cyclical` |

Apply the read-the-titles test before delivery: read only the titles in order.
The deck's story must hold on its own. If a title reads like a slogan or a
question, it is not carrying the argument.

## 2. One claim per slide

- A slide's body proves its title's claim; do not load a slide with several
  independent arguments.
- Prefer short, parallel fragments over paragraphs. If a paragraph survives,
  the point usually belongs in the speaker notes instead.
- Split a slide when it makes more than one claim (see `workflow.md`).

## 2.1 Title length and line breaks

- Draft titles for the available geometry, not for a document page. Prefer a
  title that fits in one line; use a deliberate two-line hierarchy when the
  claim needs a qualifier or paired metric.
- For Chinese mixed with Latin text, model names, dates, numbers, and units,
  choose the semantic break explicitly. Do not leave wrapping to punctuation.
- Keep inseparable phrases together: product/model names, value + unit, dates,
  percentages, and comparison operators.
- If a title exceeds two designed lines, shorten the claim or move detail into
  a subtitle/body. Shrinking type is the last option.

## 3. Prohibited phrasing patterns

Do not use these constructions. They are statistically over-represented in
AI-generated text and instantly read as machine-made. Replace each with a
direct statement.

| Pattern | Avoid | Prefer |
| --- | --- | --- |
| Negative contrast · 否定式排比 | 这不是一次升级，而是一场变革 | 本次更新增加批量处理、键盘快捷键与离线模式 |
| Hollow equation · 空洞判断句 | 数据是决策的基石 | 决策前先核对成本、转化、留存三类数据 |
| Stacked slogans · 三/四段式堆砌 | 三管齐下，全方位赋能增长 | 列出真实机制，用实际数量（两项或如实） |
| Slogan titles · 伪金句标题 | 一切尽在掌握 / 赢在未来 | 渗透率从 12% 到 38%，靠三项渠道动作 |
| Vague attribution · 模糊归因 | 行业报告显示市场快速增长 | IDC 2025 年报告：该市场年增 23% |
| Promotional adjectives · 宣传性语言 | 提供强大而丰富的功能 | 支持批量处理、快捷键与离线缓存 |
| Em-dash stacking · 破折号堆砌 | 周期——从 6 周——缩短到 3 周 | 周期从 6 周缩短到 3 周 |
| Filler phrases · 填充短语 | 值得注意的是，工单量下降 18% | 工单量下降 18% |
| Hollow optimism · 空洞乐观结尾 | 未来可期，我们正迈向新的台阶 | 下一季度在华东三个城市上线 |
| Bilingual padding · 括号翻译混排 | 我们的 KPI（关键绩效指标）提升 20% | 关键指标提升 20%（全篇术语统一） |
| Ungrounded numbers · 无出处断言 | 我们处于行业第一 | 2025 Q3 电商类目市占率第一（附来源） |
| Escalating contrast · 不仅…而且 | 不仅提升了效率，而且改善了体验 | 效率提升 30%，工单量下降 18% |

AI-vocabulary hits to avoid in either language: 赋能、抓手、闭环、洞察、宝贵、
至关重要、强调、打造、构建、深耕、聚焦、全面 / moreover、crucial、vital、
enhance、foster、empower、leverage、seamless、robust、comprehensive、delve。
These words rarely carry information; replace them with the action or result.

## 4. Preferred wording

- **Concretize numbers**: carry units, a time range, and a definition
  (`转化率提升 30%` → `首屏转化率从 12% 升到 38%（2025 Q1–Q4）`).
- **Claims first**: the title states the conclusion; the body supplies the
  evidence that supports it.
- **Two beats beat three** unless the content is genuinely three. Rule-of-three
  stacking is an AI tell; a real third item is fine.
- **Vary rhythm**: do not give every bullet the same length and skeleton.
- **Least words that carry the claim**: if a word can be deleted without losing
  meaning, delete it.
- **Trust the reader**: no hedging unless the uncertainty is real and material.
  Do not explain a metaphor you used.
- **Active voice**: `我们上线了……` not `……被我们落地`.

## 5. Evidence and sourcing

- Cite verified sources on the slide where evidence appears; never invent a
  source, author, or statistic.
- If a number cannot be sourced, either drop it or state it as a range with the
  method (`按样本量 120 的调研估算`).
- Screenshots, figures, and data visualizations communicate evidence; use them
  only when they do. Never add an image just to meet a quantity target.

## 6. Speaker notes and animation

- Notes may be fuller prose; keep the slide itself claim-first.
- Do not put the entire speech on the slide.
- Add element animations or click-steps only when the user requests them or the
  deck is clearly for a live talk; keep it to 1–3 simple groups per page.

## 7. Pre-delivery checklist

- [ ] Titles read as a complete story (read-the-titles test).
- [ ] No banned phrasings remain (scan for 不是…而是、——、赋能/闭环/抓手、
      至关重要、值得注意的是、未来可期、not only…but also、moreover).
- [ ] Every claim has evidence or a source on the same slide.
- [ ] Numbers carry units, a time range, and a definition.
- [ ] No invented citations or unsourced "第一/最快" claims.
- [ ] One claim per slide; paragraphs moved to speaker notes.
- [ ] Every title fits its intended line count with deliberate semantic breaks.
