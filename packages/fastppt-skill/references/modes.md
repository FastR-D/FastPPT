# Narrative modes

Intent defines why the deck exists; narrative mode defines how the argument
moves; theme defines visual expression. Never collapse these into one choice.

- `pyramid`: lead with the answer, then support it with grouped evidence. Use for
  decisions and executive persuasion.
- `instructional`: move from goal and prerequisites through ordered actions to
  verification. Use for teaching and operating procedures.
- `narrative`: establish context, tension, turning point, resolution, and next
  action. Use for persuasive change stories.
- `showcase`: organize around memorable artifacts or capabilities, with proof
  and differentiation attached to each. Use for demos and portfolios.
- `briefing`: progress from situation and facts to implications, risks, and
  requested action. Use for status and intelligence updates.

Record the selected mode in `deck-plan.json`. Mode changes slide order and
transitions, but does not override factual accuracy or the active theme Skill.
