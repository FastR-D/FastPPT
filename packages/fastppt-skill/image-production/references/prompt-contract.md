# Prompt contract

Write prompts from the slide's communication job, not from isolated aesthetics.
Include the subject, visual metaphor, composition, intended crop, palette
relationship, text-safe region, material/style, and exclusions. Describe labels
and numerical claims as editable Slidev overlays rather than image content.

Use a landscape crop for slide-wide visuals, square crops for cards, and portrait
crops only when the selected layout reserves a vertical panel. Keep focal content
away from the edges and from the declared text-safe region.

For edits, identify the input asset, what must stay unchanged, the requested
change, and whether the output is illustrative or evidentiary. Do not edit an
evidence image in a way that changes its factual meaning.
